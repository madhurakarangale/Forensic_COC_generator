# Forensic Chain of Custody System

A comprehensive digital forensic evidence management system with chain of custody tracking.

## Features
- User Authentication (Login/Signup)
- Case Management
- Evidence Tracking
- Chain of Custody Forms
- Real-time Updates
- PDF Report Generation
- Responsive Design

## Tech Stack
- HTML5, CSS3,  JavaScript
- Supabase (Backend)
- Font Awesome Icons
- Google Fonts
